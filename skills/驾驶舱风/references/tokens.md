分类配色(圆环、分段的小圆点):游戏 = `acc` 蓝,教育 = `green`,动漫 = `orange`。新项目照「一类一个色,只用这三个 + 灰」来分。

首字头像四种底色轮着用:蓝(`acc_bg` / `acc`)、紫(#efeafe / #5b3fc4,深色 #2a2342 / #b9a7ff)、青(#e0f4f1 / #0f6e62,深色 #16302e / #5fd3c4)、灰(`soft` / `tx2`)。**不用红、不用橙**(会像报错)。

## 状态胶囊(文字 → 颜色)

| 文字开头 | 色调 | 底 / 字 |
|---|---|---|
| 没发成、失败、出错 | bad | `bad_bg` / `bad` |
| 要处理、不确定、结果不明、还差、多发、跳过 | warn | `warn_bg` / `warn` |
| 已发、发完、够了 | ok | `ok_bg` / `ok` |
| 能发、正在…、摆好、排队 | acc | `acc_bg` / `acc` |
| 其它 | plain | `soft` / `tx2` |

## 字

- 字体:Windows `'Microsoft YaHei UI','Microsoft YaHei'`;网页 `"PingFang SC","Microsoft YaHei UI","Microsoft YaHei",system-ui,sans-serif`。
- 正文 13px;说明 12px(最小);卡片标题 15px 粗;页标题 20px 粗;统计数字 24~26px 粗。
- 大字区:收起 52px、展开 26px,粗体,收起时字距 -1px。
- 两种字重就够:常规、粗体。

## 圆角 / 间距 / 阴影

- 大字区 16px,问题卡片 18px,面板 / 列表 / 统计卡 14px,输入框和普通按钮 8px,导航项 10px。
- 胶囊按钮:圆角 = 高度的一半(主按钮 38px 高 → 19px;收起时 50px 高 → 25px)。
- 页面外边距 24px,卡片之间 12px,卡片内边距 14~16px。
- 阴影只给卡片一层很淡的:模糊 28、往下 4、黑色 7% 透明度。别的地方不要阴影。
