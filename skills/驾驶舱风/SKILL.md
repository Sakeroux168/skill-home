# 驾驶舱风

用户的原话:「真正意义上的用户一眼就看得懂、玩得懂,UI 简单、高级」「不仅要好看,还要用起来方便快捷」「字不能淡」。
这个风格就是照这几句话一点点磨出来的。用的人是公司运营,不懂技术,一天几百条重复操作 —— 界面要做到**扫一眼就知道现在怎么样、下一步点哪、点了会怎样**。

参考实现:`E:\软件\百家号发布软件\企鹅号发布助手\gui\`(theme.py、widgets.py、api_tab.py、today_tab.py)。

## 先读哪个

- 做 **Qt 桌面软件**(PySide6 / PyQt6):读 `references/pyside6.md`,直接用 `assets/qt_theme.py`(两套颜色 + 整段 QSS,拷进项目就能用)。
- 做 **网页**(后台、工具页、小程序管理端):读 `references/web.md`,直接用 `assets/web_theme.css`。
- 颜色表和每个颜色是什么意思:`references/tokens.md`(两边共用)。

## 八条规矩

### 1. 每页先给答案:一句大字 + 一行下一步 + 一个主按钮

页面最上面是「大字区」(Hero):
- **大字**说现在的状况,带数字:「7 条可以发了」「今天还差 10 条」「3 条要先处理一下」「这天的都发完了 √」。不写「欢迎使用」「数据概览」这种不带信息的话。
- **小字**一行,说接下来干什么:「还有 4 条有点小问题,处理好能多发 4 条」「去罐头里检查,点『发布』」。
- **主按钮**就在旁边,按钮上的字是动词 + 数量:「现在发布 7 条」「摆下一批」「再发一次没发成的 2 条」。
- 大字的颜色跟着状态走(tone):正常黑、好了绿、要处理橙、出错红。

为什么:用的人不想读页面,只想知道「现在要不要我动手、动哪里」。答案放最上面,一眼就够。

大字区有两种摆法:
- **收起(默认)**:明细藏起来,大字、按钮、问题卡片居中在一栏里(最宽 ~920px),大字很大(收起 52px / 展开 26px),页面上下留白,像驾驶舱的仪表。
- **展开**:点「看每个号的明细(N 条)」,大字区缩成一条卡片(大字左、按钮右),下面露出列表。收起 ↔ 展开要有过渡动画(高度和字号一起变),不要「啪」一下跳。

### 2. 一页只有一个主按钮

最该点的那一个是**实心蓝色大胶囊**;其他的:次要的是灰色胶囊(pill),再次要的是蓝字链接(link),不常用的收进「更多 ▾」菜单。
- 容易点错的两个(比如「到点自动发…」和「现在发布」)之间拉开距离,中间隔一段空白。
- 一个按钮管不过来的批量操作,用「更多」下拉,不要一排十个按钮。

### 3. 问题做成卡片

每类问题一张白卡片:左边带色块的图标,一句话(「8 条横屏 / 偏方」),下面一个蓝字处理按钮(「转标准竖屏」)。
- 没问题时卡片不消失,而是打绿勾、字变灰(「没有横屏 / 偏方」)—— 让人知道这项查过了。
- **还没查 / 没数据**时不要打绿勾(假装没事),写「横屏 / 偏方:还没查」,灰色。
- 卡片三张一排,鼠标移上去边框变蓝,点卡片空白处 = 点它的按钮。

### 4. 明细默认收起;列表要好扫

- 列表按「组」(号 / 人 / 类别)分组,组那一行:圆形首字头像 + 名字 + 条数 + 状态胶囊 + 小进度条(今天 3/20)。
- 状态用**彩色小胶囊**画,不用整行刷颜色(整行只铺很淡的底色)。
- 上面一排「全部 7 / 要处理 3 / 能发 4 / 已发 0」分段按钮(Segmented),数字跟着变。
- 做完的组沉到最下面、变灰、收起、名字后面写「· 发完了」;给个「只看没做完的」开关。
- 搜索框是圆角灰底,聚焦变白加蓝边;Ctrl+F 聚焦。

### 5. 颜色只表达意思

| 意思 | 颜色 | 用在 |
|---|---|---|
| 能做 / 主操作 / 链接 | 蓝 `acc` | 主按钮、能发、选中的导航 |
| 好了 / 已完成 | 绿 `ok` | 已发、够了 √、打勾 |
| 要处理 / 提醒 | 橙 `warn` | 要处理、多发了、选中状态下的按钮 |
| 出错 / 危险 | 红 `bad` / `danger` | 没发成、会真发真删的按钮 |
| 不用管 / 占位 | 灰 `mu` / `dim` | 说明字、还没查、发完了的组 |

- 同一个意思全软件只用一种颜色(「已发」不能这里绿那里灰)。头像别用红色,红只留给出错。
- 两套主题:浅色(默认)、深色。设置里换了**当场生效**(颜色都从主题里取,别写死在控件上)。
- **字不能淡**:正文 `#111318`,说明字最浅 `#4b5260`,最小 12px。用户原话「白色界面有些字看不见好淡」。
- 深色主题下按钮底色要单独压暗(`acc_btn`、`danger_btn`),保证白字看得清。

### 6. 话要像人说的

- 全用大白话。不写「操作失败」「请求异常」「NULL」,写清楚**什么事 + 下一步怎么办**:「号的密钥不对 → 去设置里『登录取钥匙』」「文件被改名了,点『刷新』再发」。
- 数字带单位,用「条 / 个号 / 分钟」:「还要约 4 分钟」「转竖屏:已转 40 / 113 条」。
- 中文标点。按钮 1~5 个字,动词开头。确认框里第一行(红字加粗)写最要紧的后果:「现在马上发出去(不是定时),发了只能去后台删」。
- 行话旁边放一个小「?」,鼠标放上去一句话解释(「偏方 = 画面不是标准竖屏 9:16 …」)。
- 空状态是一句引导,不是道歉:「这天没有视频 —— 换一天看看,或者点『给号选文件夹…』」。

### 7. 防手滑(这条比好看重要)

- **会真发出去 / 真删掉 / 改不回来的操作,确认框默认按钮是「先不」**,按回车 = 不做;真做的那个按钮是红色的,字写清楚「现在发出去」「开始摆,并自动发布」。
- 按钮上写这次管几条;**选中了东西时**,主按钮换颜色(橙)并改字「只发选中的 1 条」,旁边出一个「× 取消选中」;切页签 / 清空搜索 / 改完一条后自动取消选中。
- 所有按钮跟着选中走:选了只管选中的,没选管看得见的全部。
- 批量改东西先预览(「会改 22 条,先看一眼:…」),改完能撤销。
- 删除前先挪走 / 留原片;实在要删,只删空的。

### 8. 小地方要有生气

- 打开软件一个 1 秒多的开场(「Hi,欢迎使用本工作台」淡入淡出),能在设置里关。
- 进度用**圆环**(今天发了多少)、**横进度条**,数字滚动着变上去。
- 长任务给进度 + 剩多久 + 一点趣味:纸飞机沿进度条飞、每秒网速小波浪线、轮播一句生活小知识或损人小段子。
- 卡片淡淡的阴影;切页、展开收起用 200~400ms 的缓动动画。
- 图标统一一套线性图标(Windows 上用 Segoe MDL2 Assets / 网页上用一套 outline 图标),不混用 emoji。

## 页面骨架

```
┌──────────┬───────────────────────────────────────────────┐
│ ◉ 软件名 │  要发哪天的: [10.24(今天)▾]  刷新  昨天还剩 4 条 ›  │
│  副标题   │                                               │
│          │            7 条可以发了                         │ ← 大字(状态色)
│ ☀ 今天   │     还有 3 条有点小问题,处理好能多发 3 条          │ ← 下一步
│ ▣ 页面一 │                                               │
│ ▣ 页面二 │      [到点自动发…]        [ 现在发布 7 条 ]        │ ← 次要 pill + 主按钮
│ ▣ …   (4)│                                               │
│          │  ┌─────────┐ ┌─────────┐ ┌─────────┐          │
│          │  │✓ 没有横屏│ │! 3 条标题│ │▦ 查水印  │          │ ← 问题卡片
│          │  │ 转竖屏   │ │ 整理标题 │ │ 检查     │          │
│ ⚙ 设置   │  └─────────┘ └─────────┘ └─────────┘          │
│ 第 N 版  │          ﹀ 看每个号的明细(12 条)                │
└──────────┴───────────────────────────────────────────────┘
```

- 左边导航 176px:顶部软件名 + 一行小字副标题,图标 + 名字,选中的蓝底蓝字;右边能挂橙色数字角标(两位数时要变宽,别切成「1(」)。最底下「设置」和版本号。
- 第一页是「今天」:大字「今天还差 N 条没发」+ 进度条、三个圆环卡片(分类)、「出问题 N 条」红边卡片、「下一步」清单(每行一个图标 + 一句 + 「去发」按钮)、「今天发了这几批」时间线。

## 交付前自己过一遍

- [ ] 每页最上面一句话说清楚现在怎么样,带数字;旁边只有一个主按钮。
- [ ] 主按钮字 = 动词 + 数量;选中了东西时按钮变色改字。
- [ ] 会真发 / 真删的确认框:回车 = 先不,真做的按钮是红的,第一行红字写后果。
- [ ] 没数据 / 没查的地方没有绿勾;空状态有一句引导。
- [ ] 颜色只表达意思,同一个意思同一个颜色;深色主题下没有看不清的字;换主题当场生效。
- [ ] 字号最小 12px,说明字不浅于 `#4b5260`。
- [ ] 小屏(1366×768)放得下:弹窗按屏幕可用高度开,长路径中间省略。
- [ ] 圆角不大于控件高度的一半(Qt 里圆角太大会画成直角,见 pyside6.md「坑」)。
- [ ] 全是大白话,行话旁边有小问号。

## 和用户打交道

- 用户是运营,不懂技术:改界面前先用大白话说方案,或者画个草图给他看(他说「可以」再做)。
- 他喜欢「先给我看几个风格选」,做新页面时可以给 2~3 个草稿让他挑。
- 改完给截图(浅色 + 深色各一张最好),说清楚「哪里变了、在哪点」。
