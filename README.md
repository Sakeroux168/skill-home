## 已收藏 Skill

### 1. 角色偷拍感抓拍摄影

- **路径**：`skills/角色偷拍感抓拍摄影/SKILL.md`
- **一句话用途**：把角色设计成“远距离抓拍 / 前景遮挡 / 偷偷观察感 / 偷拍感”的氛围摄影提示词。
- **适合什么时候用**：想做朋友圈氛围图、角色 COS 抓拍、街头长焦、咖啡店/商场/地铁等自然抓拍感画面时使用。
- **特点**：不走标准棚拍，强调不完美构图、遮挡、距离感、长焦和偶然被拍到的感觉。
- **上游参考**：已发现 `vibeshotclub/vsc-skills/character-candid-photography` 有对应版本，后续可用于检查更新。

### 2. 人像角色设定师

- **路径**：`skills/人像角色设定师/`
- **一句话用途**：把“我想要什么气质的人”拆成具体人脸结构、五官、骨相、妆容，并生成完整中文生图提示词。
- **适合什么时候用**：想从零设计原创人物、同妆不同脸、固定脸换妆、固定妆换脸，或者需要把抽象气质变成具体长相时使用。
- **特点**：重点不是拍摄方式，而是“这个人到底长什么样”，会细化脸型、眼睛、鼻子、嘴唇、眉毛、颧部、下颌和妆容。
- **来源**：`nuyoah-ai-works/nuyoah-portrait-character-designer`
- **收藏版本**：v0.2.1（整套原文件保留）

### 3. 监控摄像头视角摄影

- **路径**：`skills/监控摄像头视角摄影/SKILL.md`
- **一句话用途**：把 IP 角色、宠物或虚构成年人物放进电梯、门铃、天花板监控、行车记录仪、猫眼等固定机器镜头中，生成真实监控录像感的摄影提示词。
- **适合什么时候用**：想做“机器一直在看”的监控氛围、角色日常被固定摄像头记录、九宫格系列图或带小剧情的连续监控画面时使用。
- **特点**：支持 `n=10` 多机位模式和 `series=9` 同机位连续记录模式；强调固定机位、桶形畸变、红外夜视、低清压缩、时间戳和中间状态事件；最后一张可用“直视镜头”收尾。
- **来源**：用户提供的完整帖文 Skill 提示词（原文收藏）

### 4. 艺术动画

- **路径**：`skills/艺术动画/`（入口 `SKILL.md`）
- **一句话用途**：让 coding agent 用代码画动画并渲染成 mp4：35 种艺术风格（梵高、莫奈、8-bit……）、8 种可用 JSON 直接出片段的解说动画语法（白板、Vox、财经图表、动态文字……），以及长卷穿越片骨架。
- **适合什么时候用**：想做艺术风格短片、科普/解说视频里的动画段、给自己的口播配动画画面，或想拆解复刻一段参考动画时使用。
- **特点**：先写镜头表再动手；自带拆解、验收和“反 PPT”门禁脚本，画面太死板会判红灯不出片。人物按作者规范用生图出帧、代码合成；没有生图工具时只出手和背影，或不出人。
- **运行需要**：能执行代码的 agent（Claude Code、Codex、Cursor 等），以及 uv、ffmpeg、Playwright Chromium。Playwright 版本要和本机 Chromium 对上，云端环境可固定版本，例如 `uv run --with playwright==1.56.0 ...`。
- **来源**：`alchaincyf/huashu-art-motion`
- **收藏版本**：v1.0.0，上游 commit `2d1584f9b7421278ba08f6269399c24c17977c94`（整套原文件保留）
- **许可证**：代码和文档 MIT；字体 OFL；笔顺数据 Arphic；花叔卡通形象、角色帧和 Clawd 相关示范只用于示范，不随 MIT 授权，详见该目录 `README.md`。

### 5. 驾驶舱风

- **路径**:`skills/驾驶舱风/`(入口 `SKILL.md`)
- **一句话用途**:自家的界面风格 —— 每页一句大字说结论 + 一个大主按钮、问题做成卡片、明细能收起、颜色只表达意思、全是大白话、会真发真删的操作默认「先不」。
- **适合什么时候用**:做或改任何桌面软件(PySide6 / PyQt)、网页后台、工具页面的界面时;说「用驾驶舱风」「照企鹅号那个软件的风格」就用它。
- **特点**:八条规矩 + 两套颜色(浅色 / 深色)+ 现成的 Qt 主题文件(`assets/qt_theme.py`)和网页 CSS(`assets/web_theme.css`),还有踩过的坑(圆角太大 Qt 画成直角、换主题白底白字……)。
- **来源**:自己做的,从「企鹅号发布助手」(Sakeroux168/qq-video)的界面提炼,2026-10-23。

## 使用方式

需要时直接 clone 本仓库，再取出对应 Skill 使用；外部 Skill 合集则按收藏卡里的上游地址获取。

以后新增 Skill 时，首页至少要写清楚：

1. **一句话用途**
2. **适合什么时候用**
3. **路径**
4. **来源/版本**（如果来自外部仓库）

> 原则：收藏的 Skill 尽量保留原始内容，避免未经确认的改写；外部仓库没有明确许可证时，优先保存来源和版本信息，不直接复制整仓内容。
