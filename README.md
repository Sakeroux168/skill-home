# Skill Home

Skill 之家。

用于收藏在网上看到的优秀 Skill、提示词模板、工作流规则和其他值得保留的 AI 使用方案。

## 已收藏 Skill

### 1. 角色偷拍感抓拍摄影

- **路径**：`skills/角色偷拍感抓拍摄影/SKILL.md`
- **一句话用途**：把角色设计成“远距离抓拍 / 前景遮挡 / 偷偷观察感 / 偷拍感”的氛围摄影提示词。
- **适合什么时候用**：想做朋友圈氛围图、角色 COS 抓拍、街头长焦、咖啡店/商场/地铁等自然抓拍感画面时使用。
- **特点**：不走标准棚拍，强调不完美构图、遮挡、距离感、长焦和偶然被拍到的感觉。

### 2. 人像角色设定师

- **路径**：`skills/人像角色设定师/`
- **一句话用途**：把“我想要什么气质的人”拆成具体人脸结构、五官、骨相、妆容，并生成完整中文生图提示词。
- **适合什么时候用**：想从零设计原创人物、同妆不同脸、固定脸换妆、固定妆换脸，或者需要把抽象气质变成具体长相时使用。
- **特点**：重点不是拍摄方式，而是“这个人到底长什么样”，会细化脸型、眼睛、鼻子、嘴唇、眉毛、颧部、下颌和妆容。
- **来源**：`nuyoah-ai-works/nuyoah-portrait-character-designer`
- **收藏版本**：v0.2.1（整套原文件保留）

## 使用方式

需要时直接 clone 本仓库，再取出对应 Skill 使用。

以后新增 Skill 时，首页至少要写清楚：

1. **一句话用途**
2. **适合什么时候用**
3. **路径**
4. **来源/版本**（如果来自外部仓库）

> 原则：收藏的 Skill 尽量保留原始内容，避免未经确认的改写。
